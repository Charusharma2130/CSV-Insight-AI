# CSV-Insight-AI

CSV-Insight-AI is an AI-powered data analysis dashboard built using Python, Pandas, Streamlit and Google Gemini.

The main idea behind this project is simple: a user can upload a CSV file and the application automatically analyzes the dataset and presents the results in an easy-to-understand dashboard.

Instead of writing separate Python code every time for basic data analysis, this project brings common data analysis tasks together in one application.

## Project Overview

When we receive a new dataset, the first step is usually to understand the data.

We need to know:

- How many rows and columns are present?
- What type of columns are available?
- Which columns are numeric or categorical?
- Are there missing values?
- Are there duplicate records?
- What are the important patterns in the data?
- Are there relationships between numeric columns?
- Are there unusual or extreme values?

CSV-Insight-AI performs these initial analysis tasks automatically after a CSV file is uploaded.

The project also uses Google Gemini to provide deeper AI-based analysis and generate a complete analysis report.

## Main Features

### 1. CSV File Upload

Users can upload a CSV file directly through the Streamlit dashboard.

The application reads the uploaded dataset using Pandas.

### 2. Dataset Overview

The application provides a quick overview of the uploaded dataset, including:

- Number of rows
- Number of columns
- Missing values
- Duplicate rows

### 3. Dataset Preview

The dashboard displays the dataset so users can quickly understand the structure and contents of their data.

### 4. Automatic Column Detection

The application automatically detects the available columns and separates them into:

- Numeric columns
- Categorical/Text columns

The project does not depend on fixed column names.

### 5. Missing Value Analysis

The application checks the dataset for missing values and shows which columns contain missing data.

### 6. Automatic Insights

The application generates useful insights from the available numeric and categorical columns.

For numeric data, it can provide information such as averages, minimum and maximum values.

For categorical data, it can identify frequently occurring categories.

### 7. Correlation Analysis

The application analyzes numeric columns and calculates correlations between them.

This helps identify relationships between different numeric variables.

### 8. Outlier Analysis

The application performs statistical analysis on numeric columns to identify possible outliers or unusual values.

### 9. Data Quality Analysis

The application checks different aspects of the dataset, including:

- Data types
- Missing values
- Unique values
- Duplicate rows

This gives the user a quick idea about the quality of the dataset.

### 10. Gemini AI Analysis

Google Gemini is integrated into the application to provide deeper analysis of the uploaded dataset.

Instead of only showing numbers and statistics, Gemini can explain important patterns and observations in a more understandable way.

### 11. AI Analysis Report

The application can generate a complete AI-powered analysis report.

The report is generated as a Markdown file and can be downloaded from the dashboard.

### 12. Dynamic Visualizations

The application provides dynamic charts based on the available columns in the uploaded dataset.

Currently supported visualizations include:

- Histogram
- Scatter plot
- Bar chart

The visualizations are generated dynamically instead of using fixed column names.

## Project Architecture

The project is divided mainly into a backend analysis layer and a Streamlit frontend.

### Backend – app.py

`app.py` contains the main data analysis and AI-related functions.

It handles tasks such as:

- Loading the dataset
- Detecting columns
- Dataset overview
- Automatic insights
- Correlation analysis
- Outlier analysis
- Data quality analysis
- Gemini AI analysis
- AI report generation

### Frontend – streamlit_app.py

`streamlit_app.py` contains the Streamlit user interface.

It displays the results generated by the backend and provides the interactive dashboard for the user.

The frontend uses the actual backend functions instead of duplicating the analysis logic.

### Supporting File – data_analysis.py

`data_analysis.py` contains supporting data analysis functionality used by the project.

## Dynamic Dataset Support

One of the important parts of CSV-Insight-AI is that it is designed to work with different CSV datasets.

It does not depend on fixed columns such as:

Name
Age
Math
Science

For example, one dataset might contain:

Salary
Experience
Department

while another dataset might contain:

Temperature
Humidity
City

The application detects the available columns and performs the analysis according to the uploaded dataset.

This makes the project more flexible and reusable.

## Installation

Clone the repository:

git clone https://github.com/Charusharma2130/CSV-Insight-AI.git

Go to the project folder:

cd CSV-Insight-AI

Install the required packages:

pip install -r requirements.txt

## Gemini API Setup

The project uses Google Gemini for AI-powered analysis.

Create a `.env` file in the project folder and add:

GEMINI_API_KEY=your_api_key_here

The API key should never be written directly inside the Python source code or uploaded to GitHub.

The `.env` file is kept inside `.gitignore`.

## Run the Application

Start the Streamlit application:

streamlit run streamlit_app.py

After running the command, Streamlit will provide a local URL.

Open the URL in your browser and upload a CSV file to start analyzing the dataset.
